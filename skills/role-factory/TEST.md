# 人工核对清单：role-factory

不自动跑。改过本技能或评审本技能时，按下面逐条试一次。

1. **先查重**：要求建角色时，第一动作应是 `list_bots` 并报出同名 / 同 section / 职责重叠三类；直接给 instructions 即为不符。
2. **覆盖前备份**：覆盖已有 Bot 时，应先给旧指令备份路径，并写明「覆盖会替换全部指令，不是追加」。
3. **只裁三处**：按项目裁剪只动路径与仓库名、专属边界、模型与 effort；角色职责、硬边界编号、检查清单结构一字不动。
4. **来源行与临时目录那条**：生成的 instructions 末尾同时有「写操作先在临时目录试」那条与 `来源：role-factory v<版本> · references/roles/<角色>.md`。
5. **不越权**：调用方无 Main 权限时只产出文本，不得声称已建或已改。
6. **分档引用**：接单时应看到专家给出的 A/B/C 分档（见 `roles/专家.md`「改动分级」）；缺分档应提醒补。
7. **漂移体检只报差异**：被要求体检时输出「哪些 Bot 的指令落后 / 缺行 / 裁剪值过期」，不自动重建；全部一致时写「无漂移」。
8. **交接不代编**：换届时交接摘要由旧身写，本技能只搬记忆文件与调度。

备注：第 7 条对应的口径见 `references/flow.md` 第 12 节。
