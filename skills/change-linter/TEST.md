# 人工核对清单：change-linter

不自动跑。改过本技能或评审本技能时，按下面逐条试一次。

1. **该跑才跑**：改完 `.py` / `.sh` 后按点名或角色指令加载；没有代码改动时不该主动跑。
2. **分级对得上**：只改注释或常量 → 报 L1；改到签名、类型或跨文件接口 → 报更高一级；一律报满级或一律报 L1 都算不符。
3. **缺工具如实报**：把某个检查器换成不存在的命令 → 应报「未校验 + 缺哪个工具」，不得写成通过。
4. **verify 行**：输出含 `verify: <结果>`；红项写进 `Failed or skipped:` 并归因。
5. **不自行放宽**：不得为过绿而加 `# noqa`、改阈值或跳过用例；出现即记缺陷。
6. **不吞错误**：工具自身崩溃时保留原始报错，不得改写成「已通过」。
7. **作用域**：只检查本次改动的文件，不顺手扫全仓存量问题（用户明确要求时除外）。
8. **命令原样可复跑**：报告里的命令可以直接复制执行，且不依赖本机特殊路径。
